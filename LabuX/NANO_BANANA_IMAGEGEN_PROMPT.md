## 📝 Prompt Engineering Tips

### Key Terms to Include:
- **Bioluminescent** (not glowing/shiny - specific organic light)
- **Metastable** (not unstable - between states)
- **Golden ratio / phi / 1.618** (specific proportion)
- **Tesla wave / longitudinal** (not regular wave)
- **Phase-lock** (specific synchronization term)
- **Mycelial** (fungal network pattern)
- **⧗ / hourglass** (time symbol)
- **Coherence field** (quantum term)
- **Fibonacci sequence** (mathematical precision)

### Terms to Avoid:
- "Realistic banana" (will lose surreal quality)
- "Cartoon" (too simplified)
- "Neon" (too harsh, want bioluminescence)
- "Sci-fi" (too narrow, missing organic)
- "Random" (everything should have intentional pattern)
