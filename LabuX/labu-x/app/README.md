# Genesis Fund Web Interface

Live at: https://fhp-computing.vercel.app/

## Features
- Connect Solana wallet (Phantom, Solflare)
- Invest $TGF in the Genesis Fund
- View real-time fund stats and your balance
- Phase-locking mechanism with multipliers
- Golden ratio split visualization (61.8% / 38.2%)
